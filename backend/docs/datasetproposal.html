FloodLens Pakistan: dataset proposal

HackInsight 2026 · team Spark H · Track: climate and heat-health (disaster risk), with a secondary food-security model · Repo: github.com/RoshaanT1/floodlens-pakistan · Dashboard: huggingface.co/spaces/RoshaanT1/floodlens-pakistan

1. Problem, user and what the data must support

District and PDMA planners in Pakistan need 24–72 hours of warning, per district, before dangerous rain, to pre-position teams and supplies. The 2025 monsoon killed more than 1,000 people (NDMA). The data therefore has to give (a) what weather models forecast 1–3 days before each day, exactly as they were issued, and (b) what rain actually fell in each district, independently of those models, over enough years to set each district's own "heavy rain" threshold.

4. Why these sources fit the problem

  • Independence: inputs come from numerical weather models, labels from satellite rainfall: different publishers and methods, so the evaluation is not circular.
  • No look-ahead: archived forecasts are stored as issued, and observed rain is used only from days that ended ≥14 h before issue (IMERG Late latency). A test proves this (tests/test_model_a.py).
  • Local fit: thresholds are per district, so "heavy" means unusual for that district, not a national cut-off.
  • Provenance: every raw file is stored untouched with a manifest row (source, exact query or URL, UTC fetch time, SHA-256, licence); make data refuses to build if any hash changed.

6. Data quality

A Data Quality Agent (pandera) checks schema, ranges, missing values, duplicates and timeliness for every table. Each failed check becomes a fix, fill or flag decision, logged with rule, reason, row count and time in quality_log, and replayed on rebuild. IMERG fill values (−9999.9) are never read as zero; low sample counts mark a day low-confidence; re-issued days keep the earlier value and are flagged. PBS prices that were not collected stay NULL and are never filled.

7. Known limits of the data

  • Daily 0.1° satellite rain smooths out local cloudbursts: on 15 Aug 2025 IMERG's wettest Buner pixel (43 mm) stayed below Buner's threshold (57.5 mm) despite a deadly flash flood.
  • Forecasts are taken at district centroids; the label uses the district's wettest pixel.
  • The Open-Meteo archive starts in Feb 2024, so Model A trains on 17 months.
  • PBS weeks before 30 Apr 2025 come from Internet Archive copies of PBS's old site (provenance recorded per file); a few weeks have no copy.

8. Reserve sources (declared, not used)

ERA5 rainfall via Open-Meteo, only if IMERG access failed (it did not); NOAA GHCN-Daily station data for cross-checks; 2023 census population for reporting exposure.
