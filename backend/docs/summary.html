FloodLens Pakistan

District heavy-rain warnings 1–3 days ahead and a weekly food-price watch · HackInsight 2026 · team Spark H

Problem and user

The 2025 monsoon killed more than 1,000 people in Pakistan (NDMA). District and PDMA planners need 24–72 hours of notice, per district, to decide where to pre-position teams and supplies and where to issue local warnings.

Approach

  • Model A (primary): probability that a district's wettest-pixel rain exceeds its own 95th percentile of wet-day rain (NASA IMERG Late, 2015–2023), 1–3 days ahead, from archived weather-model forecasts (Open-Meteo Previous Runs) and observed rain lagged ≥14 h.
  • Model B (secondary, data ready): weekly price change for 51 items in 17 cities (PBS SPI), 169 weeks collected.
  • Insight Agent: answers from NDMA sitreps and advisories, quoting the exact section, with numbers inserted from tables with row IDs. It says "I don't know" when nothing matches, points emergencies to Rescue 1122 and NDMA/PDMA, and has Urdu output.

Pipeline

  • Hourly Prefect flow: fetch new data → raw files + manifest (source, query, UTC time, SHA-256, licence) → rebuild all tables in a scratch DB → quality agent (fix/fill/flag, logged and replayed) → score → publish status.json for the dashboard.
  • make data rebuilds everything from the frozen raw snapshot and refuses any file whose hash changed.
  • Leakage tests: forecast inputs only from forecasts issued 1–3 days ahead; observed rain only from days that ended ≥14 h before issue. Fixed splits; the test set is locked in code.

Limits

  • Predicts heavy rain, not floods or damage; not an official warning.
  • Forecast inputs are taken at district centroids; labels use the wettest pixel.
  • The run history misses part of the window (first run 01:28 PKT; laptop slept 04:33–06:10).
  • Daily satellite rain smooths out local cloudbursts (the Buner case), so labels miss some deadly events.
  • Urdu-only questions retrieve less well than English ones.

Impact

A free, district-level rain-risk signal that planners can check every hour, with the reasons (forecast rain against the district's own threshold) and official sources one click away.
